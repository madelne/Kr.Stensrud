Website for entrepenør Kr. Stensrud & Søn AS

### Running the code locally

#### Frontend:
Direct to frontend folder and run
```sh
npm run dev
```

#### Sanity Content Manager:
Direct to sanity folder and run
```sh
npm run dev
```

### Sanity Studio:
The Sanity Content Studio is hosted at https://kr-stensrud.sanity.studio/
